# Bill Splitter

## 📌 Project Description
Bill Splitter is a beginner-friendly Python project created as part of my FreeCodeCamp learning journey. It calculates the total bill for food and drinks, adds a 25% tip, and divides the final amount equally among friends.

This project helped me practice basic arithmetic operations and understand how Python can be used to solve everyday problems.

## 🎯 Features
- Calculates the total cost of appetizers, main courses, desserts, and drinks.
- Calculates a 25% tip on the total bill.
- Adds the tip to the original bill.
- Splits the final amount equally among four friends.
- Rounds each person's payment to two decimal places.

## 💻 How to Run the Project

1. Clone or download this repository.
2. Open the project in PyCharm.
3. Open `main.py`.
4. Run the program.

```bash
python main.py
```
